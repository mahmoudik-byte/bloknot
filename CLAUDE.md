# Блокнот — приложение на телефоне

Один файл `index.html` (+ `sw.js`, `manifest.json`, иконки). Живёт на GitHub Pages: https://mahmoudik-byte.github.io/bloknot — ветка `main` и есть то, что открывается на телефоне. Списки синхронизируются с `data/bloknot.json` в репозитории `dela` («Дела»).

## Правила

- Общение на русском, на «ты», коротко, простыми словами — пользователь не программист.
- Залить в `main` (= обновить приложение у пользователя) — только после «да». До этого — своя ветка и картинки/превью.
- Перед заливкой — проверить в браузере (Playwright, Chromium уже стоит): нет ошибок, экраны и меню открываются, перетаскивание плиток работает.

## Версия (`APP_VER` в `index.html`, видна внизу главного экрана и в меню «⋮»)

Формат `X.Y.Z` (решение пользователя 24.10.2026):
- **мелкая правка** (поправил цвет, текст, баг) — меняется третья цифра: 4.0 → 4.0.1 → 4.0.2;
- **заметное изменение** (новая функция, переделка экрана) — вторая: 4.0.2 → 4.1;
- **глобальная переделка** (новый дизайн целиком, новая логика) — первая: 4.1 → 5.0.

При каждой заливке — поднять `APP_VER` и `CACHE` в `sw.js` (`bloknot-vN` → `vN+1`), иначе телефон оставит старую версию.

## Как устроено (главное)

- Данные — в браузере телефона (IndexedDB) + синхронизация с GitHub.
- У каждого списка свой значок (`glyph`, набор Lucide) и цвет (`tint`), подбираются по названию один раз (`ensureLooks`) и дальше не меняются; поменять — «⋮» → «Настроить список».
- Тема — в духе Duolingo: белые карточки с «бортиком», цвет только у значка; постоянных анимаций нет, плитки выезжают только при запуске.

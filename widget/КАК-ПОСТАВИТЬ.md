# Виджет «Срочное» на экран айфона

Большой виджет: срочные дела (отметка «Срочно» или срок сегодня/прошёл) из «Дел», отдельно — из «Работы», ниже остальные дела. Нажал на виджет — сразу диктовка, сказал — дело записалось в Блокнот (через тот же GitHub, что и синхронизация). Нажал на дело — спросит «Выполнено?».

## Один раз поставить

1. В App Store — бесплатное приложение **Scriptable**.
2. Открыть эту страницу в Safari и скопировать весь текст скрипта: https://raw.githubusercontent.com/mahmoudik-byte/bloknot/main/widget/bloknot-widget.js
3. Scriptable → «+» → вставить → сверху назвать **Блокнот** → «Готово».
4. Нажать на скрипт ▶ — попросит **ключ GitHub**: тот же, что для синхронизации Блокнота (☁️). Если старый не сохранился — сделать новый: github.com/settings/personal-access-tokens/new → имя «Виджет», срок — самый долгий → Only select repositories → `dela` → Repository permissions → **Contents: Read and write** → Generate → скопировать. Ключ хранится только в телефоне.
5. Экран «Домой» → долгое нажатие на пустом месте → «+» вверху → Scriptable → **большой** виджет → «Добавить».
6. Долгое нажатие на виджет → «Изменить виджет» → Script: **Блокнот**; When Interacting: **Run Script**; Parameter: пусто (срочные + остальные) или `срочные` (только срочные).

## Как говорить

- «Срочно позвонить юристу» → в «Дела» с отметкой «Срочно».
- «По работе отправить отчёт» → в «Работу».
- «Срочно по работе …» — и то и другое.
- После диктовки можно поправить: «Записать», «Записать срочно», «в Работу / в Дела».

Виджет обновляется сам примерно раз в 10–15 минут (так устроен айфон); после записи через него новое дело видно сразу в Блокноте после синхронизации.
